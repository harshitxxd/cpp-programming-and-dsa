MATH TOPICS FOR C++ PROGRAMMING
==============================
1. LOGARITHMS
------------

A logarithm answers the question: "To what power must we raise a base to get
a given number?"

If
    b^x = y
then
    log_b(y) = x

Here, b is the base, y is the number (the argument), and x is the exponent.
For real-valued logarithms, b must be positive and not equal to 1, and y must
be positive.

Examples:
    2^3 = 8       so log_2(8) = 3
    10^2 = 100    so log_10(100) = 2
    5^0 = 1       so log_5(1) = 0

Useful rules:
    log_b(x * y) = log_b(x) + log_b(y)
    log_b(x / y) = log_b(x) - log_b(y)
    log_b(x^k)   = k * log_b(x)
    log_b(1)     = 0
    log_b(b)     = 1

In programming, logarithms often describe how quickly an algorithm reduces
its remaining work. For example, binary search halves the search range at
each step, so searching a sorted array of n items takes O(log n) steps.
The base is often omitted in Big-O notation because changing the base only
multiplies the result by a constant:
    log_a(n) = log_b(n) / log_b(a)


2. ARITHMETIC PROGRESSION (AP)
------------------------------

An arithmetic progression is a sequence where the difference between each
pair of consecutive terms is constant. This constant is called the common
difference, d.

Example:
    4,  7,  10,  13,  16, ...
        +3   +3   +3   +3

Let:
    a = first term
    d = common difference
    n = term position (starting at 1)

The nth term is:
    a_n = a + (n - 1) * d

The sum of the first n terms is:
    S_n = n / 2 * (2 * a + (n - 1) * d)
        = n / 2 * (a + a_n)

Example: For 4, 7, 10, 13, ... the first term is 4 and d is 3.
    6th term = 4 + (6 - 1) * 3 = 19
    sum of first 6 terms = 6 / 2 * (4 + 19) = 69

The common difference may be positive, negative, or zero.

Sum of the first n natural numbers:
    1 + 2 + 3 + ... + n = n * (n + 1) / 2

Example:
    1 + 2 + 3 + 4 + 5 = 5 * (5 + 1) / 2 = 15

Slow approach (loop):
    sum = 0
    for i from 1 to n:
        sum = sum + i
This takes O(n) time and O(1) extra space.

Fast approach (formula):
    sum = n * (n + 1) / 2
This takes O(1) time and O(1) extra space.

Why the formula works:
Write the sum forwards and backwards, then add the two rows:
    S =  1 +  2 +  3 + ... + (n - 1) + n
    S =  n + (n - 1) + (n - 2) + ... +  2 + 1
    2S = (n + 1) + (n + 1) + (n + 1) + ... + (n + 1)

There are n pairs, each equal to n + 1, so 2S = n * (n + 1).
Dividing by 2 gives S = n * (n + 1) / 2.

In C++, use a sufficiently wide integer type for the multiplication. Divide
one of n or n + 1 by 2 before multiplying to reduce overflow risk:
    if n is even:   (n / 2) * (n + 1)
    if n is odd:    n * ((n + 1) / 2)


3. GEOMETRIC PROGRESSION (GP)
------------------------------

A geometric progression is a sequence where each term after the first is
found by multiplying the previous term by a constant. This constant is
called the common ratio, r.

Example:
    3,  6,  12,  24,  48, ...
        *2   *2   *2   *2

Let:
    a = first term
    r = common ratio
    n = term position (starting at 1)

The nth term is:
    a_n = a * r^(n - 1)

For r not equal to 1, the sum of the first n terms is:
    S_n = a * (r^n - 1) / (r - 1)

An equivalent form is:
    S_n = a * (1 - r^n) / (1 - r)

If r = 1, every term is a, so:
    S_n = n * a

Example: For 3, 6, 12, 24, ... the first term is 3 and r is 2.
    5th term = 3 * 2^(5 - 1) = 48
    sum of first 5 terms = 3 * (2^5 - 1) / (2 - 1) = 93


4. BINOMIAL COEFFICIENT
-----------------------

A binomial coefficient counts how many ways to choose r items from a set of
n distinct items when order does not matter. It is written as nCr ("n choose r"):
    nCr = n! / (r! * (n - r)!)

Here, n! (n factorial) means the product of all positive integers from 1 to n,
and 0! is defined as 1. The usual range is 0 <= r <= n.

Example: The number of ways to choose 2 items from 5 is:
    5C2 = 5! / (2! * 3!) = 10

Useful properties:
    nC0 = nCn = 1
    nCr = nC(n - r)
    nCr = (n - 1)C(r - 1) + (n - 1)Cr

The last property creates Pascal's triangle. Each interior value is the sum
of the two values directly above it:
    n = 0:                 1
    n = 1:               1   1
    n = 2:             1   2   1
    n = 3:           1   3   3   1
    n = 4:         1   4   6   4   1

Binomial coefficients appear in the binomial theorem:
    (x + y)^n = sum from r = 0 to n of nCr * x^(n-r) * y^r

For example:
    (x + y)^3 = x^3 + 3*x^2*y + 3*x*y^2 + y^3

In C++, factorials can become too large even for fairly small n. For many
queries, Pascal's triangle can be computed with dynamic programming using
nCr = (n - 1)C(r - 1) + (n - 1)Cr. For a single calculation, reduce
factors before multiplying or use a suitable modular-arithmetic method when
the problem asks for an answer modulo a number.


5. SLOW AND FAST POINTERS IN LINKED LISTS
-----------------------------------------

The slow/fast pointer technique (also called tortoise and hare) uses two
pointers that move through a linked list at different speeds:
    slow moves one node at a time
    fast moves two nodes at a time

Finding the middle:
    slow = head
    fast = head
    while fast is not null and fast->next is not null:
        slow = slow->next
        fast = fast->next->next

Example with five nodes:
    Start:  S,F
           |
    head ->[1] -> [2] -> [3] -> [4] -> [5] -> null

    After one step:
                   S
                   |
    head ->[1] -> [2] -> [3] -> [4] -> [5] -> null
                             |
                             F

    After two steps:
                            S
                            |
    head ->[1] -> [2] -> [3] -> [4] -> [5] -> null
                                               |
                                               F

When the loop ends, slow points to the middle. For an even number of nodes,
this version returns the second of the two middle nodes. The fast pointer
covers twice as many nodes as slow, so when fast reaches the end, slow has
covered about half the list.

Detecting a cycle (Floyd's cycle detection):
    slow = head
    fast = head
    while fast is not null and fast->next is not null:
        slow = slow->next
        fast = fast->next->next
        if slow == fast:
            a cycle exists

Example cycle; the pointers meet at node C:
    head -> [A] -> [B] -> [C:S=F] -> [D]
                   ^                         |
                   |_________________________|

Why cycle detection works:
If the list has a cycle of length L, then after both pointers enter it,
fast gains one node on slow per loop iteration (two steps versus one).
Consider their distance around the cycle modulo L. That distance changes by
one each iteration, so in at most L iterations it becomes zero. At that
point both pointers are on the same node. If there is no cycle, fast reaches
the end (null), so the loop stops without a meeting.

Finding the cycle's entry after a meeting:
    pointer1 = head
    pointer2 = meeting node
    while pointer1 != pointer2:
        pointer1 = pointer1->next
        pointer2 = pointer2->next
    the shared node is the cycle entry

Proof: Let mu be the number of steps from head to the cycle entry, and let L
be the cycle length. At the meeting, fast has traveled twice as far as slow.
Their distance difference is the slow pointer's traveled distance, which
must be a multiple of L because they meet at the same cycle node. Thus the
meeting node is mu steps backward from the entry when measured around the
cycle. Moving both pointers mu steps makes the pointer from the head reach
the entry and brings the pointer from the meeting node there as well.

Both operations take O(n) time and O(1) extra space, where n is the number
of nodes examined.


QUICK COMPARISON
----------------

Arithmetic progression: add the same value each time.
    a, a + d, a + 2d, ...

Geometric progression: multiply by the same value each time.
    a, a * r, a * r^2, ...

When implementing these formulas in C++, check the constraints before
choosing a numeric type. Large powers and sums can overflow int; use an
appropriately sized type or a safe modular-arithmetic approach when needed.
